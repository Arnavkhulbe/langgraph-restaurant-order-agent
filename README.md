The project starts with runner.py, which starts and runs the restaurant agent. It uses graph.py to control the complete workflow and decide which step should happen next. The user_input node takes the customer's message, and extraction.py understands that message and extracts the dish and quantity, such as "3 burgers" → burger + 3. Then order_confirm checks the order, using menu.py to see how much stock is available. If the order is confirmed, the cook node tries to cook it, while kitchen.py simulates whether cooking succeeds or fails. After cooking, the serve node tries to serve the food, and finally the workflow ends with SUCCESS or FAIL. Meanwhile, state.py stores all the information needed during the process, and tests/test_cases.py checks whether the whole workflow behaves correctly.
